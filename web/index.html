Overview

Recourse exposes a unified GraphQL endpoint at /graphql for all data operations, plus convenience REST endpoints under /api/v1/. All write operations require a valid JWT bearer token. An interactive GraphiQL IDE is available at GET /graphql.

High Performance

pgx/v5 native driver with connection pooling (25 conns), prepared statements, and statement-level timeouts on every connection.

Secure by Default

Quickstart

Get Recourse running locally in under 2 minutes with Docker Compose.

bash 
# 1. Clone and enter the project
cd igeTayor/recourse

# 2. Start PostgreSQL and the API

# 3. Verify health
curl http://localhost:8083/health

# 4. Open GraphiQL in browser
open http://localhost:8083/graphql

Run Natively (Go 1.25+)

bash 
# Set required environment
export DATABASE_URL="postgres://postgres:postgres@localhost:5432/recourse_db?sslmode=disable"
export JWT_SECRET="your-secure-secret-key"

# Run schema migration
psql $DATABASE_URL -f migrations/000001_create_tables.up.sql

# Start the server
go run ./cmd/server

Authentication

Recourse uses HS256 JWT tokens. All protected operations require an Authorization: Bearer <token> header. Tokens embed the user's role and permission set for zero-database-roundtrip authorization.

Register a User

graphql 
mutation Register($input: RegisterInput!) {
  register(input: $input) {
    token
    expiresIn
    user {
      id
      email
      role
    }
  }
}

// Variables
{
  "input": {
    "email": "alice@company.com",
    "password": "secure-password-123",
    "fullName": "Alice Johnson",
    "role": "USER"
  }
}

Role-Based Access Control

Four roles with a strict hierarchy. Admins supersede all roles. Roles are embedded in the JWT and enforced at the resolver level â€” no extra database round-trips.

Role Level Permissions
ADMIN 100 disputes:* users:read users:manage
ANALYST 50 disputes:read disputes:write disputes:resolve users:read
AUDITOR 30 disputes:read users:read
USER 10 disputes:read disputes:write
